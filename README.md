# FNN Placement Prediction

A Machine Learning project that predicts student placement outcomes using a Feedforward Neural Network (FNN).

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Joblib

## Features
- Data analysis and preprocessing
- Feature scaling using StandardScaler
- FNN model training using MLPClassifier
- Model evaluation and prediction probabilities
- Data visualization
- Saving and loading the trained model

## Input Features
Aptitude, Coding, Communication, Academics, and Internship.

## Output
Predicts whether a student is likely to be **Placed** or **Not Placed** based on the input features.

## How to Run
1. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib scikit-learn joblib
   ```

2. Keep `placement_data.csv` in the project folder.
3. Run the Python script:

   ```bash
   python FNN_Placement_Prediction.py
   ```
